description: work/ と output/ にある全動画の状態を一覧表示
---

以下を実行してください:

1. `npm run list` を実行する
2. 出力をそのままユーザーに表示する
3. 各動画について以下のポイントを短く補足する:
   - preprocess/jetcut/broll がどこまで進んでいるか
   - 完成物（main / shorts / edit）の有無
   - work キャッシュのサイズ
4. トータル容量も伝える
5. もしユーザーが特定の動画をクリーンアップしたい場合は `/video-cleanup <name>` の案内を添える
